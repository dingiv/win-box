# 09 从零一口气配置（精简版）：AMD 核显直通 + IDD + LG，单虚拟屏幕

> **目标形态**：宿主一个 Looking Glass 窗口运行 Windows；客机只有 **IDD 一块虚拟显示器**；
> 核显 HDMI 不接任何显示器；核显用于加速（无代码 43）。
> **本文是"照着做就行"的顺序版**，原理与排障见 01~05 篇。

## 前提

> **关于本文**：这是当时的**实录**（含走过的弯路与证据），不是使用说明。
> 命令已规整为本仓库的形式（`winbox …`）；接口以 `docs/interfaces/` 为准。

| 项 | 要求 |
|---|---|
| 平台 | AMD 核显（本文按 `1002:13c0` 写，替换成你的 ID）+ 另有一块宿主显示用的 GPU |
| BIOS | SVM/IOMMU 开；**Secure Boot 关**（kvmfr 未签名模块）；核显保持启用 |
| 宿主 | Ubuntu 26.04 / 内核 7.0（其他版本自行对应包名） |
| 其他 | 显卡直通 + LG IDD 都需要同版本组件；本文用 `B7-829-cdba29f2` |

本文用到的命令都是本仓库的 `winbox …`（接口见 `../interfaces/`）。**顺序不能换**，尤其第 3 步（趁看得见先装入口）。

## ① 宿主基础

```bash
# 一次做完：依赖 / vfio 配置（ids= + softdep）/ 从 initramfs 里删掉 amdgpu
#             / 禁掉宿主 framebuffer（内核参数）/ 用户组
sudo winbox host-prep
sudo reboot                # 必须重启（内核参数与 initramfs 才生效）

# 重启后自检：
#   lsmod | grep amdgpu        → 应无输出
#   winbox detect              → 核显的 driver 应为 vfio-pci
```

Looking Glass 宿主侧（KVMFR 模块 + 客户端依赖 + 构建客户端，一次做完）：

```bash
sudo winbox lg-prepare     # 默认 static_size_mb=128（≤1440p 可改 64）
```

---

## ② 建 VM（先是"能看见"的形态）

```bash
winbox vm-create          # q35 + OVMF(无SB) + TPM2 + SATA + e1000e
```

保持**虚拟显卡 + SPICE**（默认配置即可），然后：

1. 装 Windows（SATA + e1000e 免驱，装完即可用）；
2. 把 IVSHMEM 接进 VM（LG 的传输内存，IDD 需要它）：

```bash
sudo winbox lg-shmem     # 128MB ← /dev/kvmfr0（要与 kvmfr 的 static_size_mb 一致）
virsh start win11
```

3. 宿主起一个投送服务（把安装包送进客机）：

```bash
scp -i ~/.ssh/vm-win11 looking-glass-idd-setup.exe piagent@192.168.122.228:C:/Users/piagent/Desktop/
```

## ③ 趁看得见，把三个"入口"装好（★ 最容易漏的一步）

**在客机里**（管理员 PowerShell / cmd）：

```cmd
:: 1) Looking Glass IDD（含 IVSHMEM 驱动）——这是唯一的显示通道
curl -L -o %TEMP%\idd.exe http://192.168.122.1:8000/looking-glass-idd-setup.exe
%TEMP%\idd.exe /S /ivshmem

:: 2) OpenSSH 服务端 —— 之后盲操作时的生命线
curl -L -o %TEMP%\s.bat http://192.168.122.1:8000/guest/setup-sshd.ps1
%TEMP%\s.bat

:: 3) AMD 官方"离线"驱动（在线安装器会拒绝；提前装好，第 ⑥ 步就省事）
curl -L -o %TEMP%\amd.exe http://192.168.122.1:8000/amd-adrenalin-26.9.2-win11.exe
%TEMP%\amd.exe
```

装完重启客机。此时 LG 客户端已经可以先看一眼（画面可能还是软件模式，正常）：

```bash
winbox lg &
```

宿主自检 SSH 通道：

```bash
ssh -i ~/.ssh/vm-win11 piagent@192.168.122.228 powershell -NoProfile -Command '"SSH OK: " + $env:COMPUTERNAME'
```

## ④ 切成直通配置（这一步决定代码 43 成败）

```bash
winbox adopt && sudo winbox gpu-attach
```

它一次做齐社区已验证的四件事，并**把虚拟显卡删掉**（`video=none`）：

| # | 内容 |
|---|---|
| 1 | ROM 用**仓库成对文件**：`vbios_9800x3d.bin`（GPU）+ `AMDGopDriver_9800x3d.rom`（音频，未盖章） |
| 2 | 核显两功能挂**专属 PCIe 根端口**（同槽多功能 `00:00.0/.1`） |
| 3 | CPU 加 `topoext` |
| 4 | `x-vga=on` |

> 若脚本删虚拟显卡的部分不符合你的版本，手工确保：`<video><model type='none'/></video>`，
> 且核显的 `<rom>` 路径指向上面两个文件。IDD 与虚拟显卡**不会**同时存在。

## ⑤ 冷启动 → 复位 → 启动

```bash
sudo reboot                       # 干净冷启动（核显状态最干净）
# 重启后：
virsh start win11
winbox lg &
```

- 装好钩子后，**以后每次 `virsh start` 都会自动做一次 MODE2 真复位**，不需要再冷启动宿主；
- 端口/hook 自检：`tail -20 /var/log/lg-igpu-reset.log` 应能看到 `MODE2 reset`。

## ⑥ 客机内收尾

```bash
# 状态总览（宿主+VM+客机+客户端一把梭）
winbox status

# 若第③步没装 AMD 驱动，或驱动没绑上：现在装（可经 SSH/IDD 窗口操作），装完重启客机
# 判据：核显 Status=OK、ErrCode=0（无代码 43）

# IDD 偏好：关键一条 —— 关掉"GPU 直写传输堆"，否则会 GPU 挂起
winbox lg --idd-prefs
```

IDD 偏好（`HKLM\SOFTWARE\LookingGlass\IDD`）：

| 值 | 单虚拟屏幕场景 | 说明 |
|---|---|---|
| `ForceIndirectCopy` | **1**（必需） | 0 会让 AMD 驱动在 `HeapTest` 上直接 `Device Removed` |
| `ForceFullDirectCopy` | 0 | 设 1 会让每帧写全量（更糟） |
| `ExclusiveMonitor` | **保持默认 1** | 单虚拟屏幕正是它想要的形态（它会把别的显示器关掉）。若哪天想接物理屏再改 0 |
| `ExtraMode` / `DefaultRefresh` | 默认 | 客户端窗口大小变化会自动请求分辨率（`setGuestRes`） |

客户端配置（`~/.config/looking-glass/client.ini`）关键项：

```ini
[app]
transport=lgmp
[lgmp]
shmDevice=/dev/kvmfr0     ; 不能留空（空值会导致段错误）
allowDMA=yes
[win]
autoResize=no             ; 与 setGuestRes 互斥
keepAspect=yes
setGuestRes=yes
[input]
captureOnFocus=yes        ; 抓取模式：相对鼠标 + 指针锁在视图内（ScrLk 抓取/释放）
grabKeyboard=yes
mouseRedraw=no
```

看到 IDD 日志出现下面两行即成功（硬件模式、无 GPU 挂起）：

```
Selected render adapter AMD Radeon(TM) Graphics (vendor 0x1002, device 0x13c0)
Frame graph g=1 mode=hw 1600x900
```

最后固化：

```bash
winbox vm snapshot-save working     # ACPI 正常关机 + 拍快照
```

## 日常使用

```bash
virsh start win11                 # 钩子会自动做一次 MODE2 复位
winbox lg &    # 打开窗口
virsh shutdown win11              # 永远别用 destroy（会毁 NTFS）
winbox status         # 出问题时先跑这个
```

| 操作 | 键位 |
|---|---|
| 抓取/释放键鼠（相对鼠标） | `ScrLk` |
| 请求客机跟随窗口分辨率 | `ScrLk` + `=` |
| 窗口内移动（跨屏/挪走） | 拖拽窗口边框；`Win+Shift+方向键` 是客机内的跨显示器移动 |

## 常见偏差速查

| 现象 | 原因 / 处置 |
|---|---|
| 客机核显代码 43 | 四要素缺一：ROM 成对 / 根端口 / topoext / x-vga（见 01 篇） |
| LG 窗口黑屏无画面 | `shmDevice` 是否写了具体路径；`/dev/kvmfr0` 是否字符设备；IVSHMEM 是否挂进 VM |
| QEMU 起不来报打不开 `/dev/kvmfr0` | AppArmor/cgroup 两处放行（`winbox lg-shmem`） |
| 每次重启宿主才能用核显 | `vm start` 的复位没做成（日志看 `MODE2 reset`）；确认用的是 `sudo ./winbox vm start` |
| IDD 日志出现 `HeapTest … Device Removed` | `ForceIndirectCopy` 没设 1（IDD 会挂 GPU） |
| 物理屏花屏 | 单虚拟屏幕方案下不该有物理屏；若接了，见 05 篇（驱动缺陷，建议不插） |
