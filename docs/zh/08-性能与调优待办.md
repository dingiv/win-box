# 08 性能与调优待办

> 当前配置是为"先跑通"选的（SATA + e1000e 免驱、8 vCPU 单线程拓扑）。
> 下面是可以继续做的优化，按性价比排序。**改任何一项前先 `winbox vm snapshot-save working` 拍快照。**

## 1. virtio 驱动（最直接的 I/O 提升）

> **关于本文**：这是当时的**实录**（含走过的弯路与证据），不是使用说明。
> 命令已规整为本仓库的形式（`winbox …`）；接口以 `docs/interfaces/` 为准。

现在：磁盘走 SATA、网卡走 e1000e（当初为了免驱安装）。换成 virtio 需要客机装驱动，
`guest/virtio-win.iso`（837MB）已经下载好了。

| 项 | 现在 | 目标 | 客机驱动 |
|---|---|---|---|
| 磁盘控制器 | SATA(ahci) | `virtio-scsi` 或 `virtio-blk` | `vioscsi` / `viostor` |
| 网卡 | e1000e | `virtio-net` | `netkvm` |
| 内存气球 | virtio-balloon | 保持 | `balloon` |
| 随机数 | — | `virtio-rng` | `viorng` |

**装法**（客机管理员 PowerShell，先挂载 ISO 为 D:）：

```powershell
pnputil /add-driver D:\vioscsi\w11\amd64\*.inf /install
pnputil /add-driver D:\NetKVM\w11\amd64\*.inf /install
pnputil /add-driver D:\Balloon\w11\amd64\*.inf /install
pnputil /add-driver D:\viorng\w11\amd64\*.inf /install
```

**顺序很重要**：先把驱动**预装进驱动库**，再改 VM 的磁盘/网卡型号，否则新控制器没有驱动 → 起不来。
改完确认能进系统再删旧的 SATA 控制器。

## 2. CPU 拓扑与 `topoext`

现状：`1 socket × 8 cores × 1 thread = 8 vCPU` + `topoext`（已加，代码 43 修复的一部分）。

LG 客户端启动时的警告：

> "The host CPU has hardware threads but the guest is not aware of them.
> This can degrade latency-sensitive tasks including Looking Glass.
> For AMD CPUs, enable the `topoext` CPU feature."

主机是 8 核 16 线程。可选方案：

| 方案 | 拓扑 | 说明 |
|---|---|---|
| A（现状） | 8 vCPU `1×8×1` | 已加 topoext；最简单 |
| B | 16 vCPU `1×8×2` | 暴露 SMT，主机与客机拓扑一致；对延迟敏感任务更好，但会与宿主争核（宿主还要跑桌面+LG 客户端） |
| C | 8 vCPU `1×4×2` | 折中：暴露 SMT 但只用 8 个线程配额 |

配合 pinning（`<vcpupin>`）把 vCPU 钉在物理核上、并给 LG 客户端留出核，可进一步降延迟。

## 3. 内存与页面

- `<memoryBacking><locked/></memoryBacking>` 已开启（`mlock`，避免客机内存被换出）—— 保持；
- 如需更低延迟可上 `<hugepages>`（1G 大页），代价是宿主需预留；
- balloon 设备保留（动态回收）。

## 4. Looking Glass 侧

| 项 | 现状 | 可优化 |
|---|---|---|
| 帧传输 | LGMP + **KVMFR DMA-BUF 零拷贝** ✓ | 已是最优路径 |
| IVSHMEM | 128MB（4K 余量） | 若长期只跑 1600×900，可降到 64MB 省宿主内存（须同步改 `kvmfr static_size_mb` 与 VM 参数） |
| 音频 | SPICE USB 音频 | 可用 `sound model='ich9'` + `<audio type='spice'/>`（已配） |
| 剪贴板 | LGMP ✓ | 如需文件拖拽可再加 SPICE guest tools |
| 虚拟显示 | IDD 1600×900（`setGuestRes` 跟随窗口） | 需要更高分辨率就放大窗口（IVSHMEM 需够） |

## 5. 键鼠与体验

- 已用**抓取模式**（`captureOnFocus=yes`）：多显示器下必须（见 05/07 篇）；
- 若把 IDD 设回独占（`ExclusiveMonitor=1`），绝对定位就正确，可以关掉抓取获得"绝对鼠标"体验，
  代价是物理屏被关掉；
- `ScrLk` 释放抓取；`Win+Shift+方向键` 把窗口移到物理屏。

## 6. 宿主侧

- NVIDIA 驱动 + `nvidia-drm`：LG 客户端 EGL 渲染已跑在 5070 Ti 上（`DMA buffer support` ✓）；
- 若宿主也用核显（不推荐，会与直通冲突）：需重新考虑 amdgpu 拉黑策略；
- 建议给 `looking-glass-client` 做桌面快捷方式/开机自启（`~/.local/share/applications/looking-glass-client.desktop` 已由 `make install` 生成，可自行改成带 `--config` 的启动器）。
