## 1. 硬件与宿主

> **关于本文**：这是当时的**实录**（含走过的弯路与证据），不是使用说明。
> 命令已规整为本仓库的形式（`winbox …`）；接口以 `docs/interfaces/` 为准。

| 项 | 值 |
|---|---|
| CPU / 核显 | Ryzen 7 9800X3D / Granite Ridge `1002:13c0`（音频 `1002:1640`），位于 `0d:00.0` / `0d:00.1` |
| 主板 / BIOS | ASUS TUF GAMING B850M-PLUS WIFI7 / 1642 |
| 宿主 GPU | NVIDIA RTX 5070 Ti（`01:00.0`，宿主显示用） |
| 内核 | 7.0.0-34-generic（Ubuntu 26.04） |
| Secure Boot | **关闭**（kvmfr 未签名模块需要） |

内核命令行：

```
amd_iommu=on iommu=pt initcall_blacklist=sysfb_init video=efifb:off video=vesafb:off
```

（`initcall_blacklist=sysfb_init` 让宿主不创建 simple-framebuffer，避免占着核显显存。）

## 2. 宿主侧文件

### `/etc/modprobe.d/vfio.conf`

```
options vfio-pci ids=1002:13c0,1002:1640
softdep amdgpu pre: vfio-pci
softdep snd_hda_intel pre: vfio-pci
```

### `/etc/initramfs-tools/modules`

```
nvidia / nvidia_modeset / nvidia_uvm / nvidia_drm
vfio / vfio_iommu_type1 / vfio_pci / vfio_virqfd
# amdgpu 必须删除（blacklist 管不住 initramfs 的显式 modprobe）
```

| OpenSSH Server | 微软官方组件 | 账户 `piagent`，宿主密钥 `~/.ssh/vm-win11` |

IDD 注册表偏好（`HKLM\SOFTWARE\LookingGlass\IDD`）：

```
ExclusiveMonitor    = 0    （允许物理屏共存；默认的 1 会主动关掉其它显示器）
ForceIndirectCopy   = 1    （必需：direct 路径会让 AMD 驱动 GPU 挂起）
ForceFullDirectCopy = 0    （最小写入量）
DefaultRefresh      = 60
ExtraMode           = 1600x900@60*
```

## 5. 从零复现（命令顺序）

```bash
# A. 宿主基础
sudo winbox host-prep          # 依赖 / vfio / initramfs 清理 / 内核参数 / 用户组
sudo reboot                    # 必须重启；之后 winbox detect 确认核显已归 vfio-pci

# B. 接管或新建 VM
winbox adopt                   # 已有 VM：把身份信息提取到配置（只读 dumpxml）
# 或  winbox vm-create          # 新建（UEFI + TPM2），然后手工装 Windows

# C. ROM 与直通挂载
sudo winbox rom dump --bdf <核显BDF> ~/igpu.rom
winbox rom info ~/igpu.rom     # 确认 ID / codeType / ATOM 横幅
winbox adopt && sudo winbox gpu-attach --rom <VBIOS> --audio-rom <GOP> --mode lg

# D. 复位轮回：不用装任何钩子 —— 它是 vm start 的前置步骤
#   （启动前自动用 amdgpu 触发 MODE2 reset 再交回 vfio-pci；日志见 /var/log/winbox-reset.log）

# E. Looking Glass 宿主侧
sudo winbox lg-prepare         # KVMFR 模块 + 客户端依赖 + 构建客户端
sudo winbox lg-shmem           # 权限双闸 + 共享内存挂进 VM

# F. 启动
sudo winbox vm start           # 直通姿态下会先做核显真复位（多等 20–30 秒是故意的）
winbox lg &                    # 开窗口

# G. 客机侧一次性动作（需先建好 SSH 通道）
winbox lg --idd-prefs          # ExclusiveMonitor=0 / ForceIndirectCopy=1 / 重载 IDD

# H. 固化
winbox vm snapshot-save working   # ACPI 关机 + 拍快照
winbox status                     # 全链路自检；winbox evidence 一键取证
```

启动顺序（经验）：**宿主冷启动 → （复位轮回）→ 启动 VM → 启动 LG 客户端**。
装好 25 号钩子后，第二、三步之间不需要重启宿主。

## 6. 故障时先看哪里

| 现象 | 先查 |
|---|---|
| 客机里核显 43 | `ssh -i ~/.ssh/vm-win11 piagent@192.168.122.228 powershell -NoProfile -Command 'Get-CimInstance Win32_VideoController \| fl Name,Status,ConfigManagerErrorCode'`；再对照 01 篇的四要素 |
| VM 起不来 | 宿主日志 `tail -50 /var/log/libvirt/qemu/win11.log`（需 root）+ `winbox evidence` |
| LG 窗口无画面 | `~/.config/looking-glass/client.ini` 里 `shmDevice=/dev/kvmfr0`；`ls -l /dev/kvmfr0` 必须是 `c` 开头字符设备 |
| IDD 相关 | `winbox lg --idd-show` + 客机 `C:\ProgramData\Looking Glass (IDD)\looking-glass-idd.txt` |
| 复位 bug | `tail -40 /var/log/lg-igpu-reset.log`（钩子日志），确认出现 `MODE2 reset` |
